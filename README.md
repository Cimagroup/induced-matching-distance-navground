# induced-matching-distance-navground
Code for the short paper "The Induced Matching Distance: A Novel Topological Metric with Applications in Robotics".

To execute the code, follow the instructions:

1. Download this repository
2. Create a virtual environment in the main folder
3. Run pip install -r requeriments.txt
4. Download the repository from https://github.com/Cimagroup/tdqual in the main folder
5. Access the tdqual folder and run pip install .
6. Download the repository from https://github.com/Cimagroup/navground-blofun in the main folder
7. Access the navground-blofun folder and run pip install .

Now you should be able to run all the code in the experiments folder.
In case it doesn't work, contact jperera@us.es.
